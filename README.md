# Bleeyarima – Cybersecurity Toolkit

A collection of Python‑based command‑line security tools built for learning and portfolio.

**⚠️ Ethical Use Only** – Use only on systems you own or have explicit permission to test.

## Tools

- **Port Scanner** – TCP connect scan on common ports.
- **Keylogger** – Captures keystrokes to a log file (educational use only).
- **DNS Lookup** – Query any DNS record type.
- **Caesar Cipher** – Classic shift cipher for text encryption/decryption.

Each tool resides in its own subfolder with its own `README` and dependencies listed.

## Getting Started

1. Clone the repository.
2. Install Python 3.6+ and `pip`.
3. Install dependencies per tool (e.g., `pip install keyboard`, `pip install dnspython`).
4. Run each script with `python <tool>.py` and follow the usage instructions.

Happy learning!
